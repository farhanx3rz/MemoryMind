# MemoryMind Showcase Screenshots

This directory is designated for high-resolution visual assets and screenshots showcasing MemoryMind's Chrome Extension and research synthesis workflows for GitHub and portfolio presentations.

## Screenshot Guidelines for Portfolio Polish

1. **Resolution:** 1280×800 or 1920×1080 (clean 2x Retina / high-DPI scaling).
2. **Theme:** Use light mode with Chrome's native window frame or a clean rounded mockup container.
3. **Data:** Use realistic, engaging knowledge queries (e.g. *"Why is hybrid search more effective than pure vector search?"* or *"Summarize the attention mechanism in Transformers"*).
4. **Placement:** Add screenshots into this directory (`docs/screenshots/`) and link them in the root `README.md` using:
   ```markdown
   ![Dashboard QA](docs/screenshots/dashboard_qa.png)
   ```
