# MemoryMind Showcase Screenshots

This directory contains real application screenshots showcasing MemoryMind's Chrome Extension interfaces, settings management, and memory ingestion workflows.

---

## Active Showcase Screenshots

| Filename | View / Interface | Description |
|---|---|---|
| `01-main-interface.png` | **Popup Dashboard & QA** | Primary extension popup interface for asking questions grounded in saved memories, displaying prompt input and memory interaction controls. |
| `02-ai-provider-settings.png` | **AI Provider Settings** | Configuration view showing active provider status, credential inputs, model switching (Grok, Gemini, OpenAI, Claude, Ollama, Offline), and connection testing. |
| `03-webpage-saved.png` | **Webpage Memory Saved** | Instant one-click capture confirmation displaying the saved document status, domain metadata, and assigned topic/concept badges. |
